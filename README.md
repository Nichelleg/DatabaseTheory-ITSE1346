## Applied Database Design Exercises

### Student Enrollment Database

**Status:** Coursework exercise

Explored the relationships between students, courses,
and enrollment records.

The exercise demonstrated how relational databases
represent many-to-many relationships through an
intermediate enrollment table.

Key concepts included:

- Student and course entities
- Primary and foreign keys
- Enrollment relationships
- Referential integrity
- Organizing related records across multiple tables

### Library Database Concept

**Status:** Earlier coursework

Explored how a relational database can organize
information about library resources, borrowers,
and related transactions.

This exercise provided an introduction to how
database structures support everyday operational systems.
